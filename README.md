# Lab 3: Behavioral and Structural Sequential Blocks

## List of Exercises

### ex3.1.1 Behavioral Register File
- **Description**: Implementation of a **Register File** with 32 registers, 64-bit data width, 1 write port, and 2 read ports. The design supports synchronous read/write, synchronous reset, and enable signals.

### ex3.1.2 Synthesis of Register File
- **Description**: Synthesis of the **Register File**. Constraints were applied for clock timing and combinational paths, with results analyzed for area and timing performance.

### ex3.1.3 Windowed Register File
- **Description**: Design of a **Windowed Register File** supporting context switching for subroutine calls. The design includes global registers, local windows, and mechanisms for SPILL/FILL operations to manage memory usage.

### ex3.1.4 Synthesis of Windowed Register File
- **Description**: Synthesis of the **Windowed Register File**. Results were analyzed to compare timing and area performance against the basic Register File implementation.

### ex3.1.5 Synthesis of SI-PI-SO ALU
- **Description**: Analysis and synthesis of a **Serial-in/Parallel-in Parallel-out Arithmetic and Logic Unit (SI-PI-SO ALU)**. The design was used to explore low-power synthesis techniques and to understand serial-to-parallel conversions.
